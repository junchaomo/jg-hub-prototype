# jg-hub：九规智能中枢 企业版 MVP 演示原型

零依赖演示原型，用 Node 原生 `http` 提供静态页面与 mock API，不需要 `npm install`。目的是把 PRD 的统一入口、授权判定、数据中心、插件治理与审计口径先固定下来，再逐步替换为真实服务。

**演示默认网络：互联网（inet）。** 三网共用同一份代码与数据基线，只通过 `nets` 字段与环境配置隔离，不做真实跨网。

## 运行

```bash
cd jg-hub
node server.mjs            # 默认 http://127.0.0.1:4173
# 或指定端口
$env:PORT=5173; node server.mjs
```

需要 Node.js（本机已验证 v22.23.2 可运行）。

## 演示脚本（约 5 分钟）

0. **客户端外壳**：顶部是 38px 菜单栏——左侧后退 / 前进 / 侧栏折叠，中部「文件 / 编辑 / 视图 / 帮助」（点开是带快捷键的下拉菜单，设置、退出登录、系统状态、关于都从这里触达），右侧窗口按钮占位；其下是 58px 图标 rail（首页带未读角标、分组分隔线、底部「更多」）＋236px 会话侧栏（品牌只显示「九规智能中枢」文字、铃铛与搜索图标、新聊天、置顶、项目、最近、底部 Token 余额环与头像）。品牌与标题统一加粗黑体。
1. **首页（原「新会话」）**：主区顶部「聊天 / 工作」胶囊切换，居中「今天有什么安排？」＋胶囊输入框（附件 / 模型 / 语音 / 圆形发送），下方快捷提示词；置顶、项目、最近收在左侧会话侧栏，点「查看全部」进入完整历史。
2. **互联网环境标识**：品牌行、顶栏、输入区脚注三处同时显示当前网络（互联网 / 政务网 / 涉密内网）；账户菜单可「切换演示网络」看目录与模型差异。
3. **AI 会话**：在首页输入「查阅项目公示清单」，进入会话页——工具执行步骤（数据中心检索 → 文档解析，各带耗时与状态）、逐字流式输出、引用 chips；首页「最近」或「置顶」可回到旧会话。
4. **写操作二次确认**：输入「生成本周规划一所工作周报」，模型返回待写入文件与草稿，必须先点「确认执行」才写库并登记任务；取消则零变更。
5. **模型按环境过滤**：互联网为企业云 + 个人 API Key；切涉密内网只剩 JG-Enterprise 与 Qwen3.8-27B；工具列表同步启用/禁用。
6. **数据中心 · 五类检索**：名称与元数据之外，支持空间范围框选（拖动或选「浔阳区核心区」预设 → 服务端按 `extent` 相交命中）、文档全文、业务搜索；坐标不完整的 CAD 只在结果里提示、不参与空间索引。
7. **资源登记与处理任务**：点「登记资源」按 6 组字段（身份与分类 / 来源与权属 / 安全与授权 / 版本与关联 / 解析与索引 / 服务能力）入库；资源详情中可直接「解析重建索引」「生成预览」，生成的任务进入「任务」中心的执行记录。
8. **卫星影像**：近四季度切换、2010 年起年度归档；「卷帘对比 Q2 / Q3」同视口左右对照，标出 3 处变化图斑（含面积），并注明定量结论需专业复核。
9. **插件市场与审批**：原「精选应用」取消——其本质是插件，统一并入「插件与技能」；插件详情含功能说明、适用网络、维护人、版本记录与风险级别，提交后进入运维管理平台的插件审批队列，通过 / 驳回即改变发布状态，普通员工只看到已发布插件。
10. **云浏览器（右侧工具栏）**：不在侧栏单独占一页，由顶栏「云浏览器」按钮或菜单「视图 → 浏览器」召出右侧浮动面板。新标签页按客户端形态分为「工具」（文件 / 更多工具）与「推荐」（企业常用系统）两区，再往下是企业系统清单。面板顶部是标签页条（新标签页 + 已打开的系统 + 关闭 ×），左侧边缘可拖拽 360–820px，右上角可一键加宽 / 复原或关闭；新标签页里是「搜索或输入网址」（只命中已登记系统）、企业系统列表与安全提示；打开系统后标签内显示迷你浏览器框、掩码凭据门户、两处倾斜水印、票号与 15 分钟绑定；关闭标签 / 关闭面板均结束会话并销毁容器；身份或网络切换时服务端强制结束全部在跑会话，拒绝与放行全部入审计。
11. **人员变动工单**：入职 / 调岗 / 借调 / 离职四类，按网络分派，离职为高优先级；支持分派 → 完成 → 复核闭环，处理记录时间线可查。
12. **运维管理平台**：独立「运维管理员」角色（周航）专属入口，四个 tab——人员变动工单、运行监控、反馈管理、插件审批；监控含 5 项服务 P95 与可用性、存储用量、失败任务与告警；插件审批对待审插件执行通过 / 驳回并写审计。
13. **任务（原「我的任务」＋「自动化任务」合并）**：点导航「任务」进入任务中心，左栏 218px（任务标题、筛选 / 搜索、+ 新建任务、「已开启」列表，进行中的带蓝点），右栏未选中时是空态——时钟图标＋「安排任务」＋说明＋6 个虚线模板卡（周报草稿生成 / 公示项目变更巡检 / 影像入库核验单 / 审图意见归集 / 知识库索引巡检 / 项目节点提醒）；点模板直接预填新建表单，点「已开启」任务切到详情：立即执行 / 暂停 / 编辑＋执行记录（进度、状态、结果、失败可重试）。
14. **项目**：导航「项目」进入卡片网格，支持搜索与「新建项目」；点卡片右侧滑出详情——网络与可见范围 tag、项目说明、负责人 / 参与人 / 会话 / 资料四宫格、项目上下文说明，可「在项目中提问」把项目带进对话。首页的「项目」段与这里同源。
15. **知识库**：卡片 + 搜索，已索引 / 待解析区分，详情可「在对话中提问」把文档带进会话。
16. **图像**：按 ChatGPT 图像页形态实现——标题「图像」、热门 / 模板两个 tab、图片卡片画廊（卡片左下角为标签，生成结果排在最前并标「最近生成」），底部悬浮圆角输入条「描述新图像」含 `+`、语言、麦克风与蓝色圆形发送键，比例 / 数量 / 风格移到页头参数区；点模板会把提示词与风格回填输入框，点生成结果可下载 PNG 或「用于会话」。入口按当前绑定模型的能力判定：`JG-Enterprise（企业云）` 可进入，切到 `个人 API Key` 等未声明图像的模型时显示「当前模型不支持图像生成」并给出原因与「去设置更换模型」。
17. **插件与技能 → 企业内部插件市场**：左 250px「自定义」栏（搜索、插件 / 技能两个导航项、已安装列表、底部授权说明），右侧标题「插件」＋副标题＋公开 / 个人胶囊 tab，按「热门 / 新品推荐 / 企业内部」三分区两列行式列出插件（图标、名称、说明、范围、`+` 安装或 `✓` 已安装）。点 `+` 安装；`需授权` 范围对普通员工返回 403「该插件需部门负责人授权后安装」；点行或 `✓` 打开详情（功能说明、权限与数据、安装要求、调用记录）；右上「添加插件」提交企业内部登记审核。切「技能」页签看企业 / 个人技能与启停。
18. **个人中心与设置**：左下角头像弹账户菜单（Token 用量 12.4M/20M·62%、设置、审计、切换网络、帮助与反馈）；进入设置后主导航折叠为 58px 图标栏，设置页为「左分类导航 + 右分组行」，个人设置十类 + 管理设置六类，普通员工不渲染管理段、设置搜索也不命中。
19. **四类文档生成（PDF / Documents / Spreadsheets / Presentations）**：首页输入条「＋」菜单新增新建 PDF、新建文档、新建表格、新建演示，企业云页头也有四个新建按钮；同一张生成卡填文件名称与内容要点，确认后由服务端 `docs.mjs` 生成真实文件（自建 ZIP＋最小 OOXML 与手写 PDF，零依赖），落到企业云列表，可直接下载，中文文件名按 RFC 5987 编码。生成与下载写审计。
20. **部门云**：按部门给额度（演示：规划一所 1 TB，已用 386 GB、42 名成员共用），环形进度＋容量条；收文档、表格、演示、PDF，以及**图集**与**数据库（GDB / SHP / CAD）**——图集与数据库以“元数据＋图层目录”登记，点「查看」展示坐标系、范围与图层清单，AI 可通过 `drive_read` 读取；文件列表四列（名称、归属/共享、大小/更新时间、操作），类型胶囊区分四种格式，支持类型筛选与关键词检索；点「共享」从通讯录选人，写入共享清单与可见范围（项目内共享 / 部门可见 / 企业公开 / 授权可见）。共享后类型胶囊升级为**共享文档 / 共享表格 / 共享演示**，创建者与共享者都可点「协作编辑」进入在线编辑器（文档按段落、表格按单元格网格、演示按页与要点），保存即生成带作者、时间与说明的新版本；右侧编辑历史可回溯，有快照的版本可「恢复到此版本」并以新版本写入，不覆盖历史。PDF 只读。
21. **通讯录**：集团 10 人演示目录，按姓名、岗位、部门、邮箱检索与按部门切换；人员卡可直接「呼叫」或「发消息」，发消息跳到即时通讯并定位到该联系人。
22. **即时通讯**：左会话列表（群聊/单聊、未读数字、最后一条消息）＋右消息流（自己消息右对齐、墨黑气泡），Enter 发送、Shift+Enter 换行；消息可与项目、企业云文件联动。
23. **模块角标与通知公告**：取消首页通知中心（侧栏不再有铃铛），未读按归属挂到图标栏——任务、部门云、即时通讯、通知公告、数据中心等按钮右上角显示数字角标，进入模块即视为已读（已读按账号分别记录，换角色不串号）；无明确归属的通知收进即时通讯。企业工作台新增「通知公告」：列表按通知/公告/文章筛选、置顶与未读标识，右侧阅读区含标题、发布单位、作者、时间与正文，底部可「转发到即时通讯」「在会话中提问」；部门负责人及以上可发布（员工调用发布接口返回 403），发布与阅读写审计。
24. **全局搜索、侧栏与审计**：搜索为纯图标，Ctrl+K 唤起命令面板；点任一左侧功能按钮后侧栏默认折叠为 58px（图标竖排、组间距一致），再次点 logo 或拖拽右缘可展开；账户菜单「审计日志」抽屉含 allow / deny 记录与所属网络。
25. **教学园地**：企业工作台新增学习模块，左侧按学习视频 / 文档 / 规范文件分类并显示学习进度，右侧按类型展示播放器（时长、章节、进度条）或文档卡片（页数、摘要、标签），可「继续学习」写回进度、「用 AI 解读」把资源带进会话、「加入学习计划」。演示 8 条资源、已完成 3 条 / 6.5 学时。
26. **更多**：图标栏末尾为三点「更多」按钮，点按在右侧弹出浮层菜单（图标＋名称，常用项带图钉），列出知识库、一张图、审图平台、OA、财务管理，按角色可见性渲染；行右侧图钉可置顶，置顶后该模块图标出现在图标栏「更多」按钮下方，取消置顶回落菜单；图钉默认隐藏、悬停该行才显示（`jg.morePinned` 本地持久化）；原「精选应用」不设独立入口（本质是插件，并入插件与技能）。
27. **AI 可调用能力**：`GET /api/ai/tools` 暴露 10 个工具（检索/读取部门云、通知查询与正文、教学检索、通讯录、即时消息、知识库、空间资源、创建任务），`POST /api/ai/invoke` 以“当前员工 + 当前网络”为身份按模块授权判定并写审计；账户菜单「AI 调用能力」是系统默认能力（不是模块）：所有角色都能打开，列出工具目录与「试调用」，实际调用按员工、网络与模块授权判定，返回结构化 JSON（文档正文、表格矩阵、图集图层与坐标系等）。

## 已实现的判定逻辑

- 授权在**服务端** `canSee()` 完成：`nets` 必须包含当前网络 → `secret` 级还要求网络为涉密且用户有 `secret` scope → `all-org` 直通或 scope 交集；
- 直接 `GET /api/resource?id=...` 也会被 403 拦截，用于证明「前端隐藏不是安全边界」；
- 每次查询与拒绝都写入审计，`net` 参数化，不再硬编码某一网络；
- 空间检索由 `bboxHit()` 判定 `extent` 相交，无 `extent` 的资源返回 `noCoord` 提示。

## 与正式版的差异（不要当成已完成）

| 项 | 原型 | 正式版 |
|---|---|---|
| 数据 | 虚构 mock（`data.mjs`） | 数据中心服务 + PostgreSQL/PostGIS |
| 鉴权 | Cookie 存角色与网络，无真实令牌 | 企业 IAM 单点登录、跨网独立会话 |
| 跨网 | cookie 切换后同一基线按 `nets` 过滤 | 三网物理隔离、独立发布、独立审计 |
| 云浏览器 | 画面示意图 + 会话与票号 mock，凭据仅掩码展示 | Chromium 实例池 + 画面流网关 + KMS 凭据库，真实注入与录屏 |
| 会话 | 关键词模板 + 步骤动画，非真实推理 | jg-model-gateway 真实流式、工具编排与配额 |
| 预览 | 只给按钮与票据文案 | QGIS Server / CesiumJS / WebCAD 受控短期票据渲染 |
| 任务 | 内存态按时间推进 | 队列持久化、失败重试与结果存储 |
| 文档生成 | 原型用自建 OOXML/PDF 写出器生成四类文件，模板与样式固定 | 服务端模板库、企业样式规范、转换与版式校验流水线 |
| 企业云 | 内存配额与文件元数据，共享改内存 | 对象存储 + KMS、配额与共享策略、版本与回收站 |
| 共享文档在线编辑 | 单机内存中的内容与版本链，保存即全量版本，无并发冲突处理 | OT/CRDT 实时协同、协作者在线状态、评论与三档权限（只读/可编辑/可评论）、自动版本 |
| 通知 | 内存通知列表 + 按账号已读集合，角标按模块归属 | 消息中心服务、订阅规则、多端已读同步、推送通道 |
| 通知公告 | 内存公告与角色判定，正文为纯段落 | 发布审核流、富文本与附件、定时发布、阅读回执与归档 |
| 部门云 | 部门额度与内存元数据，图集/数据库仅存元数据与图层清单 | 对象存储 + GIS 服务，要素级授权、切片发布、版本与回收站 |
| 教学园地 | 内存资源与进度，播放器为示意 | 视频点播/CDN、课件解析、学时认证与培训档案对接 |
| AI 工具面 | 单进程工具注册表与同步调用 | 工具网关（鉴权、限流、配额、幂等）、MCP 适配、调用审计与回放 |`r`n| 更多菜单 | 图标栏三点弹层，含 5 个低频模块与图钉 | 用户自定义收藏与顺序、跨端同步 |
| 通讯录 / 即时通讯 | 10 人 mock 目录、四组会话内存态 | IAM 组织同步、消息网关、已读回执与合规留痕 |
| 持久化 | 无（重启清空） | 目录、版本、任务、工单、审计落库 |
